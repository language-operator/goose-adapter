opencode LanguageAgentRuntime installed.

Prerequisite: the `language-operator` chart must be installed first (it provides
the LanguageAgentRuntime CRD). Installing against a cluster without the CRD fails.

The runtime is cluster-scoped and can be referenced by LanguageAgents in any
namespace via spec.runtime:

  apiVersion: langop.io/v1alpha1
  kind: LanguageAgent
  metadata:
    name: my-agent
  spec:
    runtime: opencode

Image: {{ .Values.image.repository }}:{{ .Values.image.tag }}

Each agent serves its terminal on port {{ .Values.port }}, reachable in-cluster at
http://<agent-name>.<namespace>.svc.cluster.local:{{ .Values.port }}. From a browser it
is reached through the cluster ingress, behind the OIDC proxy when the LanguageCluster
enables auth.

No interactive login: opencode reaches the model gateway using the provider config
written to opencode.jsonc at startup.
